Hãy redesign lại toàn bộ giao diện CHAT của AI Tutor hiện tại.

MỤC TIÊU:
Tạo một giao diện AI Tutor hiện đại, chuyên nghiệp, sạch và có cảm giác giống các AI chat app hiện đại như ChatGPT/Claude, nhưng KHÔNG copy nguyên mẫu giao diện hoặc branding của chúng.

Quan trọng:
Không chỉ chỉnh màu sắc.
Phải thiết kế lại layout, spacing, message container, input area, sidebar và cách hiển thị code/source để giao diện thực sự giống một sản phẩm AI Tutor hoàn chỉnh.

==================================================
1. LAYOUT TỔNG THỂ
==================================================

Thiết kế theo mô hình:

┌──────────────────────────────────────────────────────────────┐
│ Sidebar │              Main Chat Area                       │
│         │                                                    │
│ Logo    │  Header                                            │
│ New Chat│                                                    │
│ Search  │                                                    │
│         │             Conversation                           │
│ Recent  │                                                    │
│ chats   │                                                    │
│         │                                                    │
│         │                                                    │
│         │                                                    │
│         │                                                    │
│ User    │                Message Input                       │
└──────────────────────────────────────────────────────────────┘

Sidebar:
- Chiều rộng khoảng 250–280px.
- Có thể collapse.
- Không chiếm quá nhiều diện tích.
- Chat area phải là khu vực nổi bật nhất.
- Trên desktop, nội dung hội thoại nằm giữa màn hình với max-width hợp lý.
- Khi user gửi message dài hoặc paste code dài, conversation container tự mở rộng theo chiều ngang trong giới hạn hợp lý.
- Không để chat bị bó hẹp thành một cột nhỏ.

Không tạo border dày.

- Username

==================================================
4. CHAT EMPTY STATE
==================================================

Khi chưa có tin nhắn:

Ở giữa màn hình:

Icon AI Tutor

"Xin chào! Tôi là AI Tutor"

"Trợ giảng hỗ trợ bạn học C# và Windows Forms."

Bên dưới hiển thị 3–4 suggestion cards:

"Giải thích Event Handler trong WinForms"

"Phân tích đoạn code C# này"

"Hướng dẫn tạo Form đăng nhập"

"Giải thích Button Click Event"

Các card phải nhỏ, đẹp, hover nhẹ.

Khi click suggestion:
→ tự động đưa nội dung vào input hoặc gửi request tùy logic hiện tại.

==================================================
5. MESSAGE LAYOUT
==================================================

Đây là phần QUAN TRỌNG NHẤT.

Không dùng kiểu:

User:
[card]

AI:
[card]

rồi mỗi message là một box có border.

Thay vào đó dùng layout giống modern AI chat:

USER MESSAGE:
- căn phải hoặc nằm trong conversation flow tự nhiên
- bubble/card nhỏ gọn
- background nhẹ
- border-radius lớn
- không chiếm full width nếu message ngắn
- message dài thì tự mở rộng.

AI MESSAGE:
- không đặt trong bubble quá nặng.
- AI response nằm trực tiếp trong conversation area.
- Avatar/icon AI ở bên trái.
- Nội dung có typography rõ ràng.
- Heading, paragraph, bullet, numbered list render đẹp.
- Markdown render tốt.
- Code block render chuyên nghiệp.

Ví dụ:

        AI icon
        AI Tutor

        Để xử lý sự kiện Button Click trong WinForms,
        bạn có thể sử dụng Event Handler...

        1. Tạo Button
        2. Đăng ký Click event
        3. Viết logic xử lý

        [Code Block]

        Sources
        ┌────────────────────────────┐
        │ WinForms Event Handling    │
        │ Page 12                    │
        └────────────────────────────┘

Không tạo bubble khổng lồ bao quanh toàn bộ AI response.

==================================================
6. USER MESSAGE
==================================================

User message phải trông giống chat hiện đại.

Ví dụ:

                         ┌──────────────────────────┐
                         │ Event Handler là gì?     │
                         └──────────────────────────┘

Nếu user paste code:

                         ┌──────────────────────────┐
                         │ ```csharp                │
                         │ private void button...   │
                         │ ```                      │
                         └──────────────────────────┘

Code phải giữ format.

==================================================
7. CODE BLOCK
==================================================

Đây là chức năng quan trọng của AI Tutor.

Code block phải cực kỳ đẹp.

Có header:

C#
                           Copy

Bên dưới:
- syntax highlighting
- line number nếu phù hợp
- horizontal scrolling
- không làm vỡ layout.

Có nút:
Copy code

Khi copy:
→ hiện trạng thái "Copied".

Nếu code dài:
→ giới hạn chiều cao hợp lý
→ scroll bên trong.

Không để code dài kéo toàn bộ trang thành một khối cực dài.

==================================================
8. INPUT AREA
==================================================

Thiết kế input giống modern AI chat.

Input nằm ở bottom.

Dạng:

┌───────────────────────────────────────────────────────────┐
│ Ask AI Tutor...                                           │
│                                                           │
│                                                           │
│ 📎        Add files                     🎤       ➤        │
└───────────────────────────────────────────────────────────┘

Input:
- bo góc lớn
- border nhẹ
- shadow rất nhẹ
- focus state đẹp
- tự tăng chiều cao khi nhập nhiều dòng
- tối đa khoảng 6–8 dòng rồi scroll.

Bên trái:
- Attach file
- Code / Insert code nếu cần

Bên phải:
- Send button

Send bằng Enter.
Shift + Enter xuống dòng.

Khi AI đang trả lời:
- Send button chuyển thành Stop generation nếu backend hỗ trợ.
- Hiển thị typing/loading indicator.

==================================================
9. FILE UPLOAD
==================================================

filename.pdf

Mà tạo attachment chip/card:

┌─────────────────────────────┐
│ 📄  winforms_basic.pdf      │
│     PDF · 2.4 MB            │
│                         ×   │
└─────────────────────────────┘

Có trạng thái:
- Uploading
- Processing
- Ready
- Error

Nếu tài liệu đang được đưa vào Knowledge Base:
hiển thị trạng thái rõ ràng.

┌─────────────────────────────────────┐

│    Chapter 2 · Page 15              │
│                                     │
│    View source →                    │
└─────────────────────────────────────┘

Nếu có nhiều source:

Sources (3)

[Source 1]
[Source 2]
[Source 3]

Không để source thành một dòng text khó đọc.

16. UX QUAN TRỌNG
==================================================

==================================================
17. PASTE CODE
==================================================

Đây là điểm đặc biệt của AI Tutor.

Nếu user paste code dài:
- phát hiện code block
- hiển thị code đẹp
- không làm input trở thành một textarea khổng lồ.
- conversation tự xử lý chiều rộng.

Ví dụ:

User:

┌────────────────────────────────────────────┐
│ C#                                         │
│                                            │
│ private void button1_Click(...)            │
│ {                                          │
│     ...                                    │
│ }                                          │
│                                            │
│ 28 lines                                   │
└────────────────────────────────────────────┘

AI:
→ phân tích code
→ vấn đề
→ nguyên nhân
→ hướng sửa
→ code đề xuất.
